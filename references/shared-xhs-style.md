# 共享规则：小红书风格库（xhs-style）

标题与正文共用的表达素材库。使用时服从 `shared-rewrite-rules.md` 的边界：素材服务于原文情绪方向，不造势、不虚构。

## 一、情绪词库

谁懂‼️ / 救命🆘 / 绝了🔥 / 破防了 / 笑不活了🤣 / 家人们 / 姐妹们 / 终于‼️ / 相见恨晚 / 后悔没早知道 / 真的会谢 / 拿捏了 / 被用明白了

使用规则：

- 情绪词必须符合原文的情绪方向；原文是平静分享，就别硬塞"救命🆘"。
- 适量：情绪词是调料不是主菜，一个标题/一个信息块一处即可。

## 二、Emoji 池

通用：`‼️ ❗️ 🆘 🔥 🤣 💔 😭 🥹 ✨ ✅ 📣`
正文补充：`💯 🙌 👀 ❤️`

使用规则：

- 标题：1–2 个为宜，服务情绪与断句节奏，别糊满。
- 正文：每个主要信息块约 1 个，替代不了文字。
- 已有合适 Emoji 的对标，保持其节奏即可，不为加而加。

## 三、同义替换示例库（手感参考，不是穷举）

| 原表达 | 可换 |
|---|---|
| 乱塞 | 乱堆 / 瞎塞 / 乱放 |
| 好看 | 绝了 / 太好看了 / 好看到犯规 |
| 好用 | 真好用 / 太省事了 / 用起来太爽 |
| 终于 | 总算 / 可算 / 终于等到了 |
| 行李箱里乱成一团 | 行李箱里乱七八糟 |
| 谁懂啊姐妹们 | 救命姐妹们 |

## 四、开头钩子类型

保留对标的钩子结构，原则上同类型替换：

| 类型 | 示例 |
|---|---|
| 痛点 | 出差党真的懂 / 每次收拾行李都崩溃 |
| 场景 | 长途飞行十小时后打开箱子那一刻 |
| 人群 | 经常旅行的人一定懂 |
| 情绪 | 谁懂啊姐妹们😭 / 救命🆘 |
| 好奇点 | 被评论区问爆的收纳袋 |
| 反差 | 20块钱的袋子治好了我的收纳焦虑 |

## 五、口语化标准（像真实用户，不像文案）

- 短句优先，一句一个意思，适合手机滑动阅读
- 有具体画面（动作、场景、结果），少抽象形容
- 有"人在说话"的语气：口头禅、停顿、感叹
- 信息明确：看完知道这是什么、好在哪、和我有什么关系

## 六、AI 腔规避清单

出现以下特征视为 AI 腔，必须改写：

- 书面关联词：首先/其次/再者/综上/因此/与此同时
- 空泛大词：极致体验 / 匠心独运 / 赋能 / 全方位呵护
- 均匀句式：连续多句长度结构雷同、排比堆砌
- 说明书口吻：本品具有… / 该产品采用…
- 过度完整：每段都四平八稳有头有尾、没有任何口语杂质
- 客套收尾：希望对您有所帮助 / 祝您生活愉快

真实感的来源：一人、一事、一感受，细节具体，态度鲜明。
